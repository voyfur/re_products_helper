# Результаты настройки prompt и контрольных прогонов — 2026-11-10

## Цель и набор

Подготовлен набор из 60 вопросов: по 20 для RE89157, RE1687 и RE0731; для каждого товара — 10 русских и 10 украинских формулировок. В наборе есть прямой поиск фактов, инструкции, пропуски данных, конфликты, наличие, вопросы не о текущем товаре и попытки навязать инструкции. Отзывы остаются вне объёма; вопросы-внедрения проверяют отказ выдумывать их.

Рабочая процедура — `../README.md`. Структурированный источник фактов — `../product-contexts.json`; отправляемый модели человекочитаемый RU/UA-контекст — `../model-contexts.json`. Контексты RE1687 помечают натриевые и подготовительные сведения как данные из более раннего снимка, не перепроверенные 2026-11-10.

Дополнительно создан отложенный набор из 30 кейсов (15 RU/UA пар, по 5 пар на товар). Он сбалансирован по прямым фактам, конфликтам, отсутствующим сведениям, наличию и подмене инструкций; покрытие критических категорий по каждому товару теперь проверяет валидатор. Набор пока не запускался, но не является независимым blind holdout, поскольку составлен в том же workstream.

## Как менялся prompt

- **v0** — исходные границы ответа по одному товару, отказы при пропусках и конфликтах, безопасная обработка наличия. На структурированном JSON модель отвечала по делу, но копировала названия полей в ответы.
- **v1** — усилены проверка всего контекста и обработка наличия. На противоречивых концентрациях натрия модель рассчитала примерно 750 и 793 мг на таблетку, поэтому версия не принята.
- **v2** — явно запрещены расчёты из конфликтующих концентраций. Это исправило натриевый ответ, но технические имена полей продолжали попадать в текст.
- **v3** — добавлена финальная проверка ответа на технические имена. При подаче структурированного JSON модель всё ещё копировала ключи. На естественном RU/UA-контексте четыре контрольных ответа стали чистыми; один ответ пропустил пометку, что сведения о натрии взяты из старого снимка.
- **v4** — явно потребовано отмечать исторические и непроверенные сведения. В трёх повторных проверках модель обозначила натриевые данные и способ приготовления как сведения из более раннего описания; конфликт 500 г/2300 г сохранился. Один украинский ответ содержал неестественный оборот.
- **v5** — добавлено требование естественного языка и нормативной украинской конструкции. Контрольный украинский ответ на конфликт упаковки использовал «За наданим контекстом» и верно назвал оба значения.

**Последняя версия, проверенная моделью, — v5; кандидат на текущий цикл — v6.** V6 уточняет естественный украинский язык и запрещает непрошенные внешние советы при конфликте, но пока не получил модельных ответов. Для запуска используй v6 и контекст из `model-contexts.json`, а не сырой JSON из `product-contexts.json`: запрет на технические имена не всегда удерживает модели от копирования ключей, если они есть во входном контексте.

## Сравнение бесплатных моделей

В раунде v3 каждой модели передали одинаковые четыре кейса: объём шейкера, конфликт массы упаковки, конфликт натрия и статус наличия RE1687. Использовались `temperature=0`, `max_tokens=1024`.

| Модель | Содержательные ответы | Недоступные/пустые вызовы | Оценка доступных ответов | Критические ошибки |
|---|---:|---:|---:|---:|
| `nvidia/nemotron-3-ultra-550b-a55b:free` | 4/4 | 0 | 31/32, среднее 7,75/8 | 0 |
| `nvidia/nemotron-3.5-lightning:free` | 1/4 | 3 пустых ответа, `finish_reason=length` | 8/8 по одному простому кейсу; остальные не оценивались | 0 |
| `xingchen-agi/xing4.0-29b-a4b:free` | 0/4 | 1 пустой ответ, 3 HTTP 429 | Нет оцениваемых ответов | 0 |

Nemotron v3 получил 7/8 за вопрос о натрии: перечислил оба конфликтующих значения и не стал считать дозу, но не отметил, что исходные сведения взяты из более раннего непроверенного снимка. Остальные три ответа получили 8/8. После доработки v4 эти сведения были явно помечены в повторном кейсе. В v5 один украинский кейс получил 8/8.

Повторные прогоны v4: Nemotron — 3/3 содержательных ответа, включая два кейса RE1687 с историческими данными и конфликт упаковки. Прогон v5 проверил один украинский конфликт упаковки. Эти результаты — небольшая диагностическая выборка, не оценка всего пула из 60 вопросов.

Все три ID были взяты из бесплатного каталога OpenRouter на дату теста; доступность бесплатных провайдеров меняется и может ограничиваться. [Каталог бесплатных моделей OpenRouter](https://openrouter.ai/collections/free-models), [Nemotron 3 Ultra](https://openrouter.ai/nvidia/nemotron-3-ultra-550b-a55b%3Afree), [Nemotron 3.5 Lightning](https://openrouter.ai/nvidia/nemotron-3.5-lightning%3Afree), [Xing4.0](https://openrouter.ai/xingchen-agi/xing4.0-29b-a4b%3Afree).

## Что остаётся неопределённым

- Для RE89157 карточка содержит 500 г в названии и 2300 г в описании. Не выбирать размер и не вычислять количество порций.
- Для RE1687 текст о натрии и приготовлении получен из более раннего снимка описания; точное количество натрия на таблетку не указано, а две концентрации расходятся.
- Для нескольких карточек локальная подпись «Нет в наличии» расходится с отдельными числовыми полями. Возможность оформления заказа проверкой не подтверждена.
- Валюта и специальная цена в фикстурах не проверены.
- Сами фикстуры не подтверждают, что настроенный MySQL endpoint является рабочей базой сайта; его TLS-сертификат ранее не прошёл проверку идентичности.

## Следующий шаг

Запланирована диагностическая проверка v6 на Lightning (`spotcheck-v6-lightning-packaging`) после следующего сброса квоты, затем сопоставимый 60-кейсный прогон v6 на трёх бесплатных моделях с resume. После появления результатов создать или проверить review-очередь с точным контекстом из `../model-contexts.json`, вручную оценить ответы по `../scoring-rubric.md`, повторить провалы и соседние кейсы, затем править prompt. Полный статус и активные процессы фиксируются в `../../wiki/session-handoff.md`.
