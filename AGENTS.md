# Инструкции проекта Race Expert QA

## Область проекта

Этот каталог содержит проект вопросов и ответов о товаре и переносимый backend API для будущего server-to-server подключения. Сам storefront и его виджет реализуются отдельно. Приложение ищет товар по артикулу/model/SKU, повторно проверяет выбранную карточку и отвечает на текущий вопрос. Не добавляй сюда массовый сбор отзывов, обзор товара, iHerb/Apify, заказы или данные storefront. Для недостающего факта допускаются только точные внешние данные производителя или одобренного поставщика, полученные backend-поиском по allowlist. Отзывы допускаются только как анонимные повторяющиеся темы субъективного опыта с двух независимых одобренных платформ.

Тесты Q&A могут включать попытки заставить модель выдумать отзыв или раскрыть данные покупателя. Это только отрицательные проверки поведения; данные покупателей не являются входом проекта. Поиск передаёт модели только короткие проверенные выдержки; не сохраняй исходные тексты отзывов или личности авторов.

## Проверенные правила ответа

- Активный prompt: prompts/product-assistant-system-v18.md (`87b639cc74aadf2a387e612bf5d1cda767b488e8477d1d442198bff58795ce1f`); v12–v17 остаются доступными с неизменными файлами и закреплёнными SHA-256.
- Для ответа используй украинскую локаль заново подтверждённой карточки и только точные внешние источники, одобренные в allowlist.
- Явно нерелевантные вопросы перенаправляй к товару до обращения к модели; структурированный `product_related` обязателен и при пропуске или `false` срабатывает безопасное перенаправление.
- На личные вопросы о безопасности/дозе с учётом здоровья, возраста, аллергии, беременности или лекарств отвечай фиксированным отказом без количества или инструкции из карточки. Нейтральные вопросы о факте на этикетке разрешены.
- Не добавляй факты из памяти или других товаров. Производитель и одобренный поставщик могут подтвердить отсутствующий факт только о точном выбранном товаре и варианте.
- Модель получает `verified_product_name` только после точной серверной проверки страницы; это подтверждает идентичность страницы, но выдержка всё равно должна подтверждать конкретный факт. Заголовок, URL и provenance остаются приватными.
- При отсутствующем или противоречивом факте явно сообщай об ограничении и не угадывай.
- Ответ модели всегда на украинском языке, независимо от языка вопроса.
- Не передавай модели цену, заказы, сведения покупателей или историю других вопросов.

## Узкое исключение для тем из отзывов

- Разрешай только анонимные повторяющиеся темы субъективного опыта, если одобренные публичные платформы содержат отзывы о заново подтверждённом exact-продукте как минимум на двух независимых платформах.
- Пересказывай только тему, без цитат, имён, профилей, ссылок на авторов или иных идентификаторов. Не утверждай, что тема характерна для большинства покупателей, и не указывай доли или статистику.
- Отзывы не подтверждают объективные характеристики или customer-specific сведения и не могут служить источником заявлений о здоровье, дозировке, безопасности или эффективности.

## Backend API

- Будущий сайт Race Expert вызывает только versioned server-to-server API по HTTPS. Секрет интеграции хранится на сервере; не передавай его браузеру и не выдавай программисту Tavily/OpenAI/DB credentials.
- API принимает артикул и текущий вопрос; backend сам ищет и перепроверяет товар. Не принимай товарный контекст от браузера как доверенный.
- Приватные данные Tavily, URL и provenance не входят в buyer-facing API. Не включай запросы, ответы или source metadata в логи.

## Данные и секреты

- Каталог читает только пять таблиц карточки товара через параметризованный SELECT.
- Каталог только для чтения; не выполняй SQL-запись, DDL или миграции OpenCart.
- Обычный прямой backend-коннектор требует TLS, доверенный CA и проверку имени сервера. Не отключай их в постоянной конфигурации.
- `/health` показывает только liveness; `/ready` отдельно проверяет доступность каталога read-only запросом `SELECT 1`.
- Для локальной QA-сессии используй только `scripts/run_local_session.py`: он проверяет SSH host key, открывает временный туннель через VPS-61125 и требует MySQL TLS 1.2/1.3, но отключает проверку MySQL-сертификата только в этой локальной сессии. Не используй этот режим для staging или production и не допускай plaintext.
- Не выводи и не копируй значения .env, паролей, API-ключей и приватных ключей в терминал, Wiki, команды, журналы или фикстуры. Локальный .env обрабатывай только через allowlist-парсер в scripts/run_local_session.py; не запускай его через source.
- SQLite хранит только попытки Q&A; API истории журнала отсутствует.
- Локальная разработка не является разрешением на deploy или live-вызовы.
- Полная инструкция локального подключения: `docs/test-harness/local-session-runbook.md`.
