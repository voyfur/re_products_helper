# История архитектурных решений Q&A

Эта справка кратко сохраняет решения, из которых выросло отдельное приложение вопросов и ответов. Это историческая заметка; актуальные ограничения задают корневые `AGENTS.md` и `README.md`.

## Решения

- Приложение построено на Python 3.12 и FastAPI.
- Каталог OpenCart читается отдельным read-only доступом через параметризованные запросы. Код Q&A использует только пять таблиц карточки товара. Для постоянного backend нужны TLS, доверенный CA и проверка имени сервера. Для одобренной локальной QA-сессии есть отдельный SSH-туннельный запускатель: MySQL TLS обязателен, но проверка сертификата отключена только на этой сессии.
- GPT-6 Luna вызывается сервером через Responses API; секрет модели остаётся только в серверной среде. Активен prompt v12, который требует украинский ответ независимо от языка вопроса.
- Отдельный SQLite-журнал хранит попытки вопрос–ответ. Снимок карточки не сохраняется и в следующие запросы автоматически не подставляется.
- Приложение предназначено для внутреннего тестирования. Отдельная копия в этой папке не развёрнута и не встроена в OpenCart.

## Текущий статус

Prompt v12 ранее был развёрнут в существующем тестовом стенде. Это не означает, что отдельная копия из папки `QA` туда развёрнута. После выкладки v12 отдельный live-вызов модели не выполнялся. Для нового развёртывания сначала нужны независимое подтверждение CA и имени MySQL-сервера, доступ для тестировщиков и лимиты запросов.
