# Историческая live-проверка Q&A — 13 ноября 2026

Эта запись сохраняет только результаты работы блока «вопрос–ответ» из старого отчёта о локальном тестовом запуске. Она описывает prompt v11 и не подтверждает поведение текущего prompt v12.

## Результат

- Поиск нашёл точные товары RE89054 и RE2672; украинские карточки загрузились.
- Два реальных запроса GPT-6 Luna завершились HTTP 200. На тот момент v11 отвечал на языке вопроса: один ответ был русским, другой — украинским.
- Попытки записались в локальный SQLite-журнал.
- При смене выбранного товара прежний вопрос и ответ оставались видны до следующей отправки. Это историческое наблюдение для старого интерфейса.

## Ограничения

- Проверка относилась к локальному стенду и не меняла OpenCart или storefront.
- В том запуске MySQL использовал обязательный TLS 1.3, но проверка сертификата и имени сервера была отключена только для этой разовой сессии. На 13.11 отдельная копия QA ещё требовала доверенный CA и проверку имени. 18.11 этот режим был перенесён в Q&A-проект как локальный запуск через SSH-туннель; он остаётся непригодным для постоянного backend, staging или production. См. [актуальный локальный runbook](local-session-runbook.md).
- Prompt v12 позже закрепил украинский язык ответа независимо от языка вопроса. После его выкладки отдельный live-вызов модели не выполнялся.
- В этот документ не переносились тексты ответов, секреты и данные покупателей.
