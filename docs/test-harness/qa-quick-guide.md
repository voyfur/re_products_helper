# Краткая инструкция по отдельному Q&A-приложению

Приложение нужно, чтобы проверить, как помощник отвечает на вопросы по одной выбранной карточке товара. Это локальный внутренний стенд, а не часть сайта.

## Как пользоваться

1. Запустите приложение по шагам из корневого [README](../../README.md). Локальный запускатель прокладывает SSH-туннель, требует MySQL TLS, а проверку сертификата отключает только для этой локальной сессии. Ключ OpenAI загружается из локального защищённого файла.
2. В поле поиска введите артикул, модель или SKU. Если найдено несколько точных совпадений, выберите нужный товар.
3. Проверьте украинскую карточку товара и задайте вопрос о выбранном товаре.
4. Помощник использует украинские данные карточки и только текущий вопрос; ответ всегда выдаётся по-украински. Если карточка не подтверждает факт, помощник не должен его угадывать.

Цена, данные заказов и покупателей, другие товары и предыдущие вопросы в запрос модели не входят.
