# Race Expert: исследование источников для Web Search

**Дата:** 2026-11-19  
**Цель:** подобрать домены для точечного поиска характеристик товара и опыта покупателей после повторной проверки карточки Race Expert.  
**Статус:** пользователь утвердил стартовый curated allowlist из этого исследования; он настроен в приложении с exact-host и brand mapping. Исследование остаётся выборочным и не покрывает весь каталог.

## Краткий вывод

Для фактов о товаре основу должны составлять официальные страницы производителя. Украинский дистрибьютор полезен как локальный дополнительный источник, только если его статус подтверждён производителем. Для опыта покупателей перспективнее всего страницы товара на Rozetka и Prom; Makeup можно рассматривать только для добавок, Epicentr пока оставить резервом. Race Expert остаётся источником идентичности выбранного артикула, но его отзывы Revizion относятся к магазину и не подтверждают свойства конкретного товара.

Для первой версии предлагается один быстрый Tavily-запрос максимум на пять результатов, ограниченный утверждёнными доменами. Вопрос об опыте покупателей требует двух независимых доменов и точного совпадения товара. Если они не найдены, тему отзывов нужно опустить. Такая политика согласуется с ограничением одного поиска и порогом двух независимых страниц в [спецификации](../specs/2026-11-19-product-qa-web-search-design.md).

## Охват исследования

Публичный каталог Race Expert показывает около 10 000 товаров в поисковом интерфейсе и включает витамины и добавки, спортивное питание, аксессуары, одежду клуба, сублимированную еду и отдельные категории «Ветеранського спорту». В спортивном питании есть гели, напитки, батончики, гидратация, восстановление, протеин, креатин, арахисовая паста и другая еда. [Каталог Race Expert](https://raceexpert.com.ua/), [страница сублімованої їжі с категориями и брендами](https://raceexpert.com.ua/sportivne-harchuvannya/sublimovana-yizha/)

Это проверка категорий и репрезентативных страниц, а не аудит каждого из 10 000 товаров. Мы не читали базу, `.env`, не вызывали Tavily и не собирали тексты отзывов. Список следует расширять по фактическим товарам Race Expert, а не по всем маркам, которые встречаются в интернете.

- **NUTREND:** `nutrend.com.ua` продаёт товары NUTREND и называет себя официальным дистрибьютором на [своём сайте](https://nutrend.com.ua/), но встречного подтверждения производителя в проверенных материалах нет. ## Рекомендованный быстрый и качественный режим

1. Сначала повторно подтвердить выбранный товар по артикулу в Race Expert. Строить запрос из бренда, полного названия и проверенных варианта/формы/вкуса/размера; сам внутренний артикул может не быть полезен на внешнем сайте.
2. Отправлять один Tavily `fast` запрос максимум на пять результатов и только по утверждённым доменам. Источники по фактам и источники отзывов должны быть раздельно размечены; отзывы производителей не считаются независимой платформой.
3. Для фактов о составе/характеристиках предпочитать производителя; использовать подтверждённого украинского дистрибьютора как локальное дополнение. При несовпадении варианта или конфликте — не подставлять «похожий» товар.
4. Для опыта покупателей считать максимум один источник на независимый домен. Воспроизводить только субъективную тему при совпадении минимум на двух доменах и точном товаре; не выводить цитаты, авторов, медицинские эффекты или заявления о распространённости темы. Иначе пропустить тему.
5. Измерить долю полезных точных результатов и задержку по локальным QA-ответам после реализации. Только по этим агрегатам расширять список/число результатов; не делать массовый обход каталога.

Стартовый runtime набор включает проверенные производительские hostnames из таблиц выше, `sponser.com.ua` и `sportpro.com.ua` только для SPONSER, `nutrend.com.ua` только для NUTREND, а также `fit.rozetka.com.ua` и `prom.ua` для отзывов. Пользователь утвердил этот набор; `makeup.com.ua` и `epicentrk.ua` исключены. SaltStick redirect и бренды из holdout списка также не включены. Runtime mapping хранит точные hostnames без wildcard и отдельные `independence_group` для Rozetka и Prom.

## Решения после утверждения стартового списка

- До расширения списка решать, нужны ли дополнительные проверенные бренды сверх стартового набора. Исследование не сверяло весь каталог и не обращалось к базе.
- Перед live QA или production отдельно проверить актуальные условия доступа и использования площадок: присутствие в allowlist само по себе не разрешает любой способ автоматизированной обработки.
- Для каждого нового review hostname назначать платформенную `independence_group`; алиасы одной площадки не должны считаться разными источниками.

## Ограничения

- В отчёте нет полного покрытия всех товаров или брендов магазина; некоторые бренды и региональные страницы оставлены на последующий SKU-level mapping.
- Число отзывов, доступность страниц и варианты на маркетплейсах изменчивы. Публичная индексация не означает разрешение на любое автоматизированное повторное использование контента.
- Не выполнялись Tavily/OpenAI-вызовы, поиск через проектный backend, подключение к базе, чтение `.env`, тестирование приложения или deploy.
